Z96A RK3568 fitfix-v3 刷写说明, 2026-11-12

文件与校验:
  u-boot.itb   1288192 字节  sha256 56398fb629f0cafa05cea2c930c8562ce6969325b3ce45e197086118cb2b691f

相对 fitfix-v2 的变化:
  仅 rk3568_vop 驱动去掉 DM_FLAG_OS_PREPARE（交接不再关 VP1 输出）
  ATF 1-6 与 u-boot.dtb 与 v2 逐字节相同；nodtb 仅差 7 字节（时间串 + 该标志位）

目标:
  eMMC sector 0x4000 (16384, 8 MiB 处)
  idbloader (sector 0x40, sha256 35c368f3...) 保持不动
  GPT / parameter / 分区表 一律不写

在线刷写 (Linux 系统内, 已验证):
  dd if=u-boot.itb of=/dev/mmcblk0 bs=512 seek=16384 conv=fsync
  dd if=/dev/mmcblk0 bs=512 skip=16384 count=2516 of=/tmp/v.itb
  sha256sum /tmp/v.itb        # 必须等于 56398fb6...

Windows RKDevTool (maskrom):
  1. 设备进 maskrom，打开 RKDevTool v3.37。
  2. 高级功能: 选择 MiniLoaderAll.bin，点“下载”，RAM 地址 0xCCCCCCCC
     (只加载到 RAM，不写 flash)。
  3. 下载镜像: 清空表格，只加一行
       eMMC / 地址 0x4000 / 路径 u-boot.itb
     勾选“强制按地址写”，点“执行”。
  4. 重启。

预期:
  上电 → LOGO → Linux 全程不黑；DRM 接管时仅一次极短闪（约 1s，属 DRM 重训 eDP）
